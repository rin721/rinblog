# 视觉证据

本目录保存 `pnpm test:e2e` 中「视觉证据」用例产出的真实浏览器截图，用于人工复核界面在改动后仍然完整。截图来自构建产物（`astro preview`，4329 端口），不来自包含草稿的开发服务器。

## 目录

| 目录 | 内容 |
| --- | --- |
| `desktop/` | 1440×900：中英文图片页、日记页、朋友页 |
| `tablet/` | 768×1024：中英文图片页、日记页、朋友页 |
| `mobile/` | 390×844：中英文图片页、日记页、朋友页 |
| `dark/` | 深色主题下的中文图片页、朋友页 |
| `screenshot-stats.json` | 每张截图的尺寸、平均亮度与通道方差 |

## 如何判读

- 截图是整页（full page）截图，因此高度随内容变化。
- `screenshot-stats.json` 中的 `spread`（通道标准差）低于 5 说明画面接近纯色，通常意味着样式没有加载；`luminance` 在深色主题下应显著低于浅色主题（当前实测约 47–92 与 217–237）。
- 像素统计只能发现「空白或样式丢失」这类问题，界面观感与设计意图仍需人工复核截图本身。

## 重新生成

```powershell
pnpm build
pnpm test:e2e -- --grep "视觉证据"
```

截图前会加载页面下方的图片，避免整页截图中的延迟加载图片留白。日记页面目前记录空状态布局，图片页面展示正式图库内容；新增图库文章会随验收重新生成对应截图。
